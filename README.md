
# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates the interest earned on a principal amount over a specific period at a given interest rate.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** Initial amount invested or borrowed.
- **Rate:** Annual interest rate (in percentage).
- **Time:** Duration in years.

## Features

- Calculate simple interest.
- Calculate the total amount (Principal + Interest).
- Easy-to-use interface.
- Simple and efficient implementation.

## Usage

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Click the calculate button.
5. View the calculated simple interest and total amount.

## Example

**Input:**
- Principal = 1000
- Rate = 5%
- Time = 2 years

**Output:**
- Simple Interest = 100
- Total Amount = 1100
